# 漫剧老李 Skill 使用说明

本 Skill 用于把小说、IP、故事创意或已有剧本，整理成可用于 AI 漫剧生产的剧本、视觉开发包、资产图册、分镜、视频提示词和成片合成清单。

它是“创作与制作规则包”，不是独立的视频剪辑软件。实际图片生成、视频生成、配音和剪辑，需要使用对应平台或已接入的工具。

## 一、在哪里使用

### 直接使用 Codex

不需要安装 OpenClaw。把项目目录提供给 Codex，并要求它读取：

```text
short-drama-director/SKILL.md
short-drama-director/使用说明.md
```

示例：

```text
请读取并遵循 short-drama-director/SKILL.md 和使用说明.md。
我想把一部古代言情小说制作成 AI 漫剧，请先询问必要信息，再按流程执行。
```

### 使用 OpenClaw

如果希望注册为正式 Skill 并使用命令路由，可以安装：

```bash
openclaw skills install ./short-drama-director --as short-drama-director
```

## 二、总流程

```text
E0 选本评分
→ E1 原著分析与剧本改编
→ E2 可视化转写与视觉开发
→ E3 合格剧本校验
→ E4 分镜标注与资产需求拆解
→ E5 人物/场景/道具资产生成与锁定
→ E6 终版分镜与视频提示词
→ E7 视频生成、剪辑合成与成片质检
```

完整规则见 [`references/end-to-end-manju-sop.md`](references/end-to-end-manju-sop.md)。

这是一条“有门禁、可断点进入”的流程，不要求每次从 E0 开始。已有材料时，从最早一个尚未通过的阶段开始。

## 三、开始前提供的信息

尽量提供以下内容：

- 原著、梗概、已有剧本或项目创意；
- 原作题材和时代背景；
- 目标平台、画幅、单集时长和预计集数；
- 目标受众和参考风格；
- 动作强度：`R1 写实克制`、`R2 商业高燃`、`R3 玄幻大招`；
- 已有角色图、场景图、分镜或视频素材；
- 题材、目标受众和制作目标；版权由人工在工作流外确认，不由 Skill 判断。

没有提供的内容可以让 Codex 先列出假设，但不能把假设当成已确认事实。

## 四、各阶段怎么用

### E0：选本评分

E0 尊重原作题材，只判断“是否值得改编成 AI 漫剧”，不会把所有小说都按古代言情评估。

评分总分 100：

| 维度 | 分值 | 重点 |
|---|---:|---|
| 开篇钩子与节奏 | 30 | 前 300 字是否有冲突或悬念 |
| 情绪与内容适配性 | 30 | 情绪落点和动作/对话可视化程度 |
| 改编落地可行性 | 25 | 人物数量、场景数量、主线清晰度 |
| 系列化与制作价值 | 15 | 可拆集程度、资产复用和视觉辨识度 |

结果：

- `80~100 分`：S 级，直接立项；
- `60~79 分`：A级，补短板后推进；
- `0~59 分`：C 级，原则上放弃；
- 版权不由 Skill 判断，默认由人工在工作流外完成确认。
- 内容安全仍在剧本和分镜阶段检查，但不计入 E0 选本价值分。

调用示例：

```text
/选本评分
请按 100 分制评估这部小说改编成 AI 漫剧的价值，尊重原作题材，不预设类型。
```

### E1：原著分析与剧本改编

长篇可先读前 10 章、关键高潮和结局进行初筛；中篇通读；短篇逐字精读。进入正式改编前，需要补齐主线、人物和关键转折的事实依据。

主要输出：

- 一句话故事：主角 + 目标 + 阻碍 + 结果；
- 主冲突、分冲突和起承转合主线节点；
- 必留名场面、关键爽点、反转和情绪爆发点；
- 故事五元素、人物关系和角色小传；
- 分集总纲、单集节拍和集末钩子；
- 五阶门控剧本。

改编原则：留主线、砍支线、去冗余、强画面。大段心理描写优先转为动作、表情、关系反应或台词，但不能删掉主线因果和核心人物动机。

### E2：可视化转写

把小说语言翻译成观众能看到或听到的内容，建立《视觉开发包》：

- 全剧画风、色彩、光影和镜头基调；
- 角色视觉 DNA、服化道和情绪状态；
- 场景空间、时间、天气、主光方向和关键道具；
- 12 节拍情绪曲线；
- 场次/镜头地图；
- `CHR / SCN / PRP / AUD / Uxx` 资产预清单。

默认优先级：

```text
动作 > 对话 > 短旁白 > 大段心理描写
```

### E3：合格剧本校验

检查剧本是否“能留住人、看得懂、演得出、接得上”：

- `0~3 秒`：钩子是否成立；
- `10~15 秒`：是否讲清主角处境、目标和阻碍；
- `25~30 秒`：是否出现小升级或转折；
- `45~60 秒`：冲突是否进入爆发或抉择；
- 结尾：是否有悬念、行动目标或追更理由；
- 外层、中层、内层冲突是否递进；
- 主角、配角、反派是否人设统一、动机合理；
- 主线、伏笔和本集目标是否闭环；
- 内容表达、时长和对白语速是否达标；版权不在此流程内判断。

输出状态：`PASS`、`REVISE` 或 `BLOCK`。

### E4：分镜标注

E4 是资产需求草案，不是最终视频提示词。遵循“单镜一单意”，每个镜头只表达一个核心信息、动作或情绪。

每镜至少标注：

```text
镜号、时长、叙事目的、主体、核心动作/情绪、景别、机位、运镜、构图安全区、光色、台词、音效、转场、连续性、资产 ID
```

默认节奏参考：钩子约 10%，冲突推进约 60%~70%，高潮约 10%~15%，结尾悬念约 10%。具体镜头数量和时长按平台、对白和模型能力调整。

### E5：资产生成与锁定

按角色、场景、道具、声音/氛围分批制作。人物使用 9:16 四视图母版；关键场景默认只做一张 45°俯视全景，有反打再补一张反打图；有多人调度时增加人物站位图，标明角色 ID、左右前后位置、朝向和运动路径；非关键场景不单独制图，直接做分镜。道具一图一件。资产必须服务剧情，不制作没有使用计划的装饰性素材。

核心资产记录：

- 唯一 ID 和版本；
- 参考图；
- 外观、服装、色彩和比例；
- 场景空间、道具和光线约束；
- 使用镜头和可复用范围；
- 状态：`Draft → Review → Locked`。

没有锁定参考图的资产不能进入终版分镜和视频投喂。

### E6：终版分镜与视频提示词

读取已锁定资产图册，回填资产引用并生成终版分镜。AI 绘画/关键帧提示词推荐按以下结构组织：

```text
风格定调
→ 全局备注（画幅、质量、无水印/字幕）
→ 固定人物/场景词与资产引用
→ 本镜画面设计
→ 时序与连续性说明
→ 反向提示词
```

每个镜头检查：安全区域、单镜一单意、人物/场景连续性、动作可生成性、画幅、对白和音效同步。

### E7：成片合成与质检

输出可交给剪辑工具的：

- 视频片段顺序和时间线；
- 音频、音效和 BGM 清单；
- 字幕文本和时间码；
- 转场和画幅参数；
- 音画同步、连续性、黑帧、错字和合规检查表。

实际图片生成、视频生成、配音、剪辑和导出由外部工具完成，除非已经接入对应插件或 API。

## 五、断点续作

直接说明已有材料和入口：

```text
我已有：
1. 完整剧本；
2. 男女主角色参考图；
3. 两个场景参考图。

请从 E3 开始，先校验剧本，再做 E4 分镜标注。
已有资产请保留，只列出缺失和不合格部分。
```

如果已有分镜草案：

```text
请从 E5 开始，根据现有分镜需求生成并锁定人物、场景和道具资产。
```

## 六、常用指令

```text
/选本评分        评估小说或 IP 是否值得改编成 AI 漫剧
/故事分析        提炼题材、人物、关系和主线
/改编策划        生成分集总纲和短剧改编方案
/写剧本          执行五阶门控剧本创作
/可视化转写      生成视觉开发包和资产预清单
/合格剧本校验    输出 PASS / REVISE / BLOCK
/分镜标注        生成资产需求草案和镜头标注
/资产图册        生成并管理人物、场景、道具资产
/做分镜          生成锁定资产后的终版分镜
/生成视频提示词  输出模型可用的视频提示词
/成片合成        输出片段、音频、字幕和时间线清单
/断点续作        从已有材料对应阶段继续
```

## 七、古代言情示例

```text
我要把一部古代言情小说改成 9:16 竖屏 AI 漫剧。
原作题材保持古代言情，不改成其他类型。
请先执行 E0 选本评分；如果达到 S 级，继续做 E1 故事分析和剧情瘦身。
后续重点保留男女主情感推进、身份冲突和关键名场面。
先不要生成图片，等 E2 输出视觉开发包和资产清单后再进入 E4/E5。
```

## 八、重要注意事项

- 原作题材保持不变，题材规则只负责适配，不负责改造类型；
- 已有材料可以跳过前置阶段，但要说明版本和来源；
- E4 是分镜需求草案，E6 才是最终投喂提示词；
- 未锁定的角色、场景和道具不能作为最终资产引用；
- 用户指定的画幅、时长和平台优先于默认值；
- 版权由人工在工作流外确认，Skill 不对版权作判断；
- AI 生成结果需要人工抽检，尤其是脸部、手部、服装、空间和跨镜连续性。
